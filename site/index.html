VoxelSieve
Features AI assistants Get started GitHub

Industrial CT volumes, sieved.

VoxelSieve removes the outside air from reconstructed CT scans, keeps the part and its internal voids, and stores the result as a sparse OpenVDB dataset. On top of it: porosity analysis, inspection reports after BDG P 202, nominal-actual comparison with the CAD model, a browser UI and an MCP server for AI assistants. Scans larger than memory work, streamed out of core.

What it does

Sieve

Raw volumes (with vendor headers) and TIFF stacks, also inside ZIP archives, become a bricked VDB dataset. Bricks with only outside air are not written. Grey values stay lossless.

Porosity

Finds pores and zones of loosened microstructure, with volumes from the grey values and cupping kept apart from porosity. On a synthetic scan of a cast bell housing every shrinkage cavity is within 2 % of the ground truth.

Inspection report

Evaluates the analysis against acceptance limits per inspection zone (BDG P 202 scheme) and writes an HTML report to print as PDF.

Nominal-actual

Aligns the CAD model (STL) to the scanned surface, from any pose, and measures the signed deviation of every surface point, with statistics and a coloured mesh.

Studio

A browser UI with slice and 3D views that load only what is on screen, a wizard, undo and redo, saved views and several objects in one coordinate system.

Learned segmentation

Material classes by grey value or a learned model run on the CPU tile by tile, scored against labels. Training scripts in PyTorch are included.

Works with AI assistants

vs-studio --mcp serves VoxelSieve over the Model Context Protocol. An assistant such as Claude Desktop or Claude Code can create projects, run the analyses, look at slices and write the report.

It runs on your computer: the scans stay where they are, and the assistant only receives results such as pore lists, measurements, slice pictures and reports.

claude mcp add voxelsieve -- \
  /opt/voxelsieve/bin/vs-studio --mcp /data/scans

> Import /data/scans/housing.raw, analyse the
  porosity and write an inspection report with
  the example order.

Get started

  1. Download a package from the latest release: an MCP bundle (.mcpb) for Claude Desktop, or an archive with all tools for Linux, Windows and macOS. A Docker image builds from the Linux package.
  2. Get the sample data: a synthetic scan of a cast housing with its CAD model, an inspection order and the ground truth of its defects.
  3. Follow the quickstart from download to a porosity report and a CAD comparison in about ten minutes.

To build from source, see the README; dependencies come from vcpkg. Contributions are welcome, see CONTRIBUTING.md.
