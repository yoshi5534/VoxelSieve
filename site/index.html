Industrial CT volumes, sieved.

VoxelSieve removes the outside air from reconstructed CT scans, keeps the part and its internal voids, and stores the result as a sparse OpenVDB dataset. On top of it: porosity analysis with inspection reports after BDG P 202 and P 203, nominal-actual comparison and wall thickness against the CAD model, dimensional measurement with first article reports, battery cells and fibre composites, a Python package, a browser UI and an MCP server for AI assistants. Scans of hundreds of GB work, streamed out of core within the memory you give it.

New in 0.7.0

  • Python package with numpy access to datasets and every operation, with wheels for Python 3.12 and newer.
  • Porosity after BDG P 203 in freely defined inspection regions (boxes, spheres, cylinders, meshes drawn on the CAD model), with the porosity key of the drawing, a reference volume at the most porous spot, pore shape, gaps and distance to the surface.
  • Beam hardening correction by reprojection of a coarse level, or by depth below the surface.
  • One memory budget for every tool: --memory, --cache and --threads hold brick caches and work memory within it; long runs report progress and can be cancelled. Porosity reads the scan half as often and is about 40 % faster on large scans.
  • 3D view down to level 0: bricks of the finer levels stream into the view within a VRAM budget where the picture needs them.

All changes are in the release notes and the changelog.

What it does

Sieve

Raw volumes (with vendor headers), TIFF, PNG and DICOM stacks, also inside ZIP archives, MetaImage, NRRD and HDF5 files become a bricked VDB dataset with a first look within seconds. Bricks with only outside air are not written. Grey values stay lossless; DICONDE goes in and out. An interrupted import resumes where it stopped.

Porosity

Finds pores and zones of loosened microstructure, with volumes from the grey values and cupping kept apart from porosity, per material when segmented. On a synthetic scan of a cast bell housing every shrinkage cavity is within 2 % of the ground truth.

Inspection report

Evaluates the analysis against acceptance limits per inspection zone (BDG P 202) or the porosity key of the drawing in freely defined regions (BDG P 203), and writes an HTML report to print as PDF.

Dimensional measurement

Measures the characteristics of a drawing on the scan: planes, cylinders and spheres found on the CAD model, datums 3-2-1 or RPS, sizes, form, orientation, position and profile against their tolerances.

First article report

Cover sheet, characteristic list with nominal, tolerance, actual value and OK/NOK, and views of the part with the balloon numbers, made by an AI assistant from scan and CAD model.

Denoising

Non-local means against the measured noise of the scan, or a learned model trained on the noisy scan alone, into a new dataset that keeps the part.

Nominal-actual

Aligns the CAD model (STL) to the scanned surface, from any pose, and measures the signed deviation of every surface point, with statistics and a coloured mesh.

Wall thickness

Wall thickness on the surface by rays or inscribed spheres, thin regions against limits, the thickness map inside the part and the deviation from the nominal thickness of the CAD model.

Beam hardening

Removes cupping and the dark streaks between dense regions from a reconstructed scan, without projections or a spectrum, and writes a corrected dataset.

Battery cells

Housing, electrode layers, anode overhang per edge, particles and voids of cylindrical and pouch cells, from the volume or from section images, with a report against the specification.

Fibre composites

Fibre directions from the structure tensor, fibre families with direction, share and spread, porosity per material and a report with requirements per family.

Python package

import voxelsieve: numpy access to datasets of any size, brick by brick, your own processing into a new dataset, and projects that run every operation. Wheels for Linux, Windows and macOS.

GUI

A browser UI with slice and 3D views that load only what is on screen, down to the finest level within a VRAM budget, undo and redo for every step, saved views and several objects in one coordinate system. On main: one-click opening, a workspace with layers and regions, colour maps, lighting and video export.

Learned segmentation

Material classes by grey value or a learned model run on the CPU tile by tile, scored against labels. Training scripts in PyTorch are included.

Works with AI assistants

vs-gui --mcp serves VoxelSieve over the Model Context Protocol. An assistant such as Claude Desktop or Claude Code can create projects, run the analyses, look at slices and write the report, up to a first article inspection report from a scan and its CAD model. Long analyses run in the background and can be cancelled.

The VoxelSieve plugin for Claude Code adds skills for the common inspection tasks: first look, porosity check, wall thickness, CAD comparison, first article, battery cell and fibre composite (/plugin marketplace add yoshi5534/voxelsieve-plugin).

It runs on your computer: the scans stay where they are, and the assistant only receives results such as pore lists, measurements, slice pictures and reports.

claude mcp add voxelsieve -- \
  /opt/voxelsieve/bin/vs-gui --mcp /data/scans

> Import /data/scans/housing.raw, analyse the
  porosity and write an inspection report with
  the example order.

Get started

  1. Download a package from the latest release: an MCP bundle (.mcpb) for Claude Desktop, or an archive with all tools for Linux, Windows and macOS. The Docker image is ghcr.io/yoshi5534/voxelsieve, the Python wheels are attached to the release as well.
  2. Get the sample data: a synthetic scan of a cast housing with its CAD model, an inspection order and the ground truth of its defects.
  3. Follow the quickstart from download to a porosity report and a CAD comparison in about ten minutes.

To build from source, see the README; dependencies come from vcpkg. Contributions are welcome, see CONTRIBUTING.md.
